# Enhanced Calculator Project

Αυτό το repository περιλαμβάνει δύο υλοποιήσεις αριθμομηχανής (κομπιουτεράκι) σε C++:

1. **Terminal Calculator**: Μια έκδοση με περιβάλλον κειμένου (console) που προσομοιώνει HUD με κουμπιά και υποστηρίζει βασικές και επιστημονικές πράξεις.
2. **Qt Calculator**: Μια πιο προχωρημένη αριθμομηχανή με γραφικό περιβάλλον χρήστη (GUI), κατασκευασμένη με το Qt Creator, που υποστηρίζει επίσης ιστορικό υπολογισμών και επεκταμένες λειτουργίες.

## 🚀 Λειτουργίες

### Console Calculator:
- Προσομοίωση κουμπιών στην κονσόλα
- Υποστήριξη πράξεων: `+`, `-`, `*`, `/`, `^`, `√`, `log`, `ln`, `sin`, `cos`, `tan`, `asin`, `acos`, `π`, `e`
- Ιστορικό αποτελεσμάτων και εκφράσεων
- Υποστήριξη αποθήκευσης/ανάκτησης αποτελεσμάτων με `#n`

### Qt GUI Calculator:
- Γραφική αριθμομηχανή με κουμπιά για αριθμούς, πράξεις και τριγωνομετρικές συναρτήσεις
- Υποστήριξη για προτεραιότητα πράξεων μέσω stack
- Εμφάνιση ιστορικού και αποτελεσμάτων
- Χρήση `QLineEdit`, `QPushButton`, `QStack`, `QVector`, `QMessageBox`

## 🛠️ Τεχνολογίες

- Γλώσσα: **C++**
- Console έκδοση: `iostream`, `vector`, `cmath`, `string`, `sstream` κ.ά.
- Qt GUI έκδοση: **Qt Widgets**, `QStack`, `QVector`, `QLineEdit`, `QGridLayout`

## 🧾 Οδηγίες Εκτέλεσης

### Console Calculator:
1. Άνοιγμα του project σε οποιοδήποτε C++ προγραμμα
2. Download του φακελου Build και εκτελεση του αρχειου Calculator.exe

## Παρατηρησεις:
1. Στο Qt Calculator δυστηχως δεν καταφερα να διορθωσω το προβλημα το οποιο υπαρχει στην ριζα, κανοντας την αχρηστη για την ωρα.
